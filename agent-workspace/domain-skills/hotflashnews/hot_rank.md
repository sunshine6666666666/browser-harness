# HotFlashNews Domain Skill (hotflashnews.com 全网热榜兜底聚合)

## Scope

`hotflashnews.com` aggregates real-time hot rankings from many Chinese
platforms (微博 / 百度 / 知乎 / 抖音 / 36Kr / IT之家 / 澎湃 / 头条 / B站 /
贴吧 / 财联社 / 凤凰网 / 华尔街见闻 / 联合早报 / 参考消息 / 格隆汇 / 金十数据)
into one page. Devkeeper uses it as a **fallback / cross-validation source**
(兜底) when a platform's native hot-rank page or a first-party extraction is
unavailable or blocked.

Current implemented extractions (all except 微博/知乎, which have first-party
devkeeper domain skills): **抖音 douyin / 百度 baidu / 36Kr / IT之家 it /
澎湃 penpai / 头条 toutiao**. Extend `CATEGORY_TABS` in hot_rank.py to add
more.

- Allowed: reading the aggregated hot-rank list, extracting top-N entries.
- Destructive boundary: never post, comment, follow, or mutate data on
  hotflashnews.com or any upstream platform.
- Hosts: `hotflashnews.com` / `*.hotflashnews.com`.

## Important data-shape note

HotFlashNews hot-rank entries have **only rank + title** (排序 + 标题). There
is **no heat value / no status badge**. Do not fabricate heat values.

Each entry also carries a platform-specific target link (e.g. Douyin entries
link to `https://www.douyin.com/hot/...`).

## UI facts (verified 2026-08-10)

Page: `https://hotflashnews.com/`.

- The "全网热榜" card sits below the 7x24 快讯 feed. Its tab bar is a
  `sticky top-0 ... rounded-t-md` container holding 8 platform tabs:
  微博 / 百度 / 知乎 / 抖音 / 36Kr / IT之家 / 澎湃 / 头条.
- Clicking a tab swaps the ranked list below it (client-side Alpine/Vue state;
  no URL change observed).
- Each rank item is an `<a class="flex gap-3 items-start ...">`:
  - rank: first child `div` (red `bg-[#fe2d46]` for idx 0, orange for 1,
    yellow for 2, gray for 3+), text = index+1.
  - title: `div.text-lg.font-medium` text.
  - href: the `a` href (platform hot link, e.g. douyin.com/hot/...).
- Item container: `div.space-y-3 p-4 pt-3` (15 items shown in the verified
  view; the list is generated by `x-for` over items).
- The page also has other tab bars (top nav 快讯/科技/财经/..., footer
  热门平台). The authoritative platform switch is the one whose container is
  anchored at the "全网热榜" heading.

## Functions

### `fetch_hot_rank(category='douyin', limit=15)`

Navigate to the homepage, click the platform tab, and return up to `limit`
entries.

```python
{"rank": "1", "title": "上海暴雨", "href": "https://www.douyin.com/hot/2603779"}
```

- `category` keys: `douyin`, `baidu`, `36kr`, `it`, `penpai`, `toutiao`
  (map in hot_rank.py; excludes weibo/zhihu which have first-party skills).
- `limit` clamps to the first N rows; pass `None` for all visible.
- Raises RuntimeError if the tab or list is missing.

### `run(category='douyin', limit=15)`

CLI-ish entry used when the file is loaded via `exec(open(...).read())` under
Browser Harness stdin scripts (the `__main__` guard does not fire there).
Prints each entry as `rank. title | href`.
